# Oxley Forecast Compare (public)

Forecasts for Oxley, QLD 4075 from several Australian weather sites, side by side.

- Site: https://d3skj3t.github.io/oxley-forecast-public
- `scraper/scrape.py` runs every 3 hours via GitHub Actions and writes `data/forecast.json`.
- Sources: Bureau of Meteorology (forecast and Archerfield observations), Weatherzone, WillyWeather,
  Elders Weather, Weather Underground and Windy.

This is a separate copy of a private app. Figures belong to the sites they come from; for warnings
and safety decisions, follow the Bureau of Meteorology.
